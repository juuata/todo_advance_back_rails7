# タスク完了チェックリスト

タスクを完了とみなす前に、以下をすべて確認すること。

## 必須チェック項目

### 1. テスト
```bash
bundle exec rspec
```
- [ ] 全テストがパス（緑）
- [ ] 新機能に対応するテストが追加されている

### 2. Lint/静的解析
```bash
bundle exec rubocop
```
- [ ] RuboCopエラーがない
- [ ] 警告も可能な限り解消

### 3. 動作確認
- [ ] Railsアプリが正常に起動する
- [ ] 該当のAPI/機能が期待通り動作する

## コミット前の確認

### 4. コードレビュー（セルフ）
- [ ] コードが読みやすい
- [ ] 不要なコード/コメントが残っていない
- [ ] セキュリティ上の問題がない
- [ ] エッジケースが考慮されている

### 5. Git
- [ ] 適切なブランチで作業している
- [ ] コミットメッセージが明確

## ワークフロー上の承認
- [ ] ユーザーからの実装計画承認を得た
- [ ] ユーザーからのコミット承認を得た
