---
description: Git コミットを実行する
---


以下の手順でgitコミットを実行してください：

1. **Gitリポジトリの確認と初期化**
   - `git status` を実行してGitリポジトリが初期化されているか確認する
   - もし初期化されていない場合は、`git init` を実行する


2. **Git設定の確認**
   - `git config user.name` と `git config user.email` を確認する
   - 設定されていない場合は、ユーザーに設定を促すか、デフォルト値を設定する
   - デフォルト値の例：
     - `git config user.name "Claude Code User"`
     - `git config user.email "claude@example.com"`


3. **変更の確認**
   - `git status` を実行して、コミットする変更があるか確認する
   - `git diff` を実行して、変更内容を確認する


4. **ステージングされていない変更の追加**
   - 変更されたファイルを `git add` でステージングエリアに追加する
   - 新規ファイルも含めて適切にステージングする


5. **コミットメッセージの作成**
   - 変更内容を分析して、適切なコミットメッセージを作成する
   - コミットメッセージは以下の形式に従う：
     - 1行目：変更の概要（50文字以内）
     - 2行目：空行
     - 3行目以降：詳細な説明（必要に応じて）
   - 日本語または英語で記述する（プロジェクトの言語に合わせる）


6. **コミットの実行**
   - `git commit` を実行してコミットを作成する
   - コミット後、`git log -1` で作成されたコミットを確認する


**注意事項：**
- .env、credentials.json など、機密情報を含むファイルはコミットしない
- そのようなファイルが検出された場合は、ユーザーに警告する
- node_modules や .next などのビルド成果物は通常コミットしない（.gitignoreで除外されているべき）
